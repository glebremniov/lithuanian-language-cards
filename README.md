# Карточки литовского языка

Небольшое статическое приложение для изучения 959 литовских слов и фраз уровня A1–A2. Выберите тему и учите слова по карточкам или откройте полный список слов с переводами. Доступны системная, дневная и ночная темы. Прогресс и выбранное оформление хранятся в браузере через `localStorage`.

## Локальный запуск

Запустите локальный сервер из папки проекта:

```sh
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000/`. При открытии `index.html` как файла браузер блокирует загрузку `words.json`. Для работы приложения не нужны сторонние зависимости или серверная часть на GitHub Pages.

## GitHub Pages

В настройках репозитория откройте **Settings → Pages** и выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`. После публикации приложение будет доступно по адресу `https://glebremniov.github.io/lithuanian-language-cards/`.

## Редактирование слов

Откройте `words.json` и найдите нужную тему. Каждая карточка занимает одну строку в её списке `cards`:

```json
{"lt": "namas", "ru": "дом"},
{"lt": "gyventi", "ru": "жить", "question": "kur?"}
```

Добавляйте строки или удаляйте их, сохраняя запятые между записями. `question` нужен только там, где полезно указать вопрос управления глагола. После изменения файла обновите страницу.
